# An isolated engineering illustration

This demo was written specifically for the public showcase. It has no authentication, network requests, analytics, payment code, persistence, or connection to kinCore data. All people and chores are fictional.

`model.mjs` is shared by the browser and tests. It shows checklist revision checks, one-time completion, stable snapshots, actual-completer attribution, and a reset next occurrence. Each successor is created as an unscheduled illustrative repeat; production uses timezone-aware recurrence rules.

For readability, demo points equal the fictional chore's estimated minutes. Production scoring includes household configuration and other captured inputs. The demo does not implement late penalties, achievement awards, database concurrency, offline storage, authorization, or provider integrations.

Use it to read a small state machine, not to infer a full production API. Refresh or Reset discards all progress. The local server binds to loopback and serves only the demo and brand mark. It is not a production hosting server.
